# 获取当前组播地址接口说明

用于回显组播地址输入框：页面加载时调用对应接口取当前默认地址，替换写死的默认值。

## 语音控制

```
GET http://192.168.1.179:8061/v1/mcast
```

返回：

| 字段 | 说明 |
|---|---|
| ok | 是否成功 |
| group | 当前默认组播地址（用户修改并保存后的地址） |
| port | 端口 |
| persisted | true=来自保存的配置；false=内置默认（尚未修改过） |

示例响应：
```json
{"ok": true, "group": "224.2.1.232", "port": 6020, "persisted": true}
```

## 实时转写

```
GET http://192.168.1.179:8000/v1/multicast
```

返回运行中的组播转写任务列表：

```json
{
  "jobs": [
    {"group": "224.2.1.235", "port": 6020, "lane_id": 0, "sentences": 120}
  ],
  "max_jobs": 8
}
```

| 字段 | 说明 |
|---|---|
| jobs[].group / port | 该任务收听的组播地址 |
| jobs[].lane_id | 占用的转写路数 |
| jobs[].sentences | 已转写句数 |
| max_jobs | 最大并发路数 |

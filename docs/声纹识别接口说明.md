# 声纹识别与说话人分离 · 前端对接说明

适用服务：multi-stream-asr（实时转写服务），基地址 `http://<板子IP>:8000`

> 部署/阈值标定/运维见《声纹识别与说话人分离说明.md》，本文只讲前端怎么对接。

## 0. 能力说明

转写结果里的每句话会带一个**说话人标识**，分两层：

- **说话人分离**：不认识的人也能分开，标 `S1`、`S2`…（按首次开口顺序编号）
- **声纹识别**：与声纹库比对命中后，直接给真实姓名（如「张三」）

前端要做的三件事：

1. 从 WS 的 `transcript` 消息里读 `segment.speaker` 并展示
2. 收到 `speaker_remap` 消息时**原子替换**本会话的旧标签
3. （可选）用 REST 接口管理声纹库（注册/查询/删除）

---

## 1. WebSocket 接收转写结果

三条链路的消息格式完全一致，只是音频来源不同：

| 场景 | URL |
|---|---|
| 浏览器麦克风推流 | `ws://<板子IP>:8000/ws/stream?sample_rate=16000` |
| 收听一路组播 | `ws://<板子IP>:8000/ws/multicast?group=224.2.110.220&port=6020` |
| 板载麦克风 | `ws://<板子IP>:8000/ws/local_mic` |

`/ws/stream` 需要前端推 PCM16 单声道二进制音频帧并发控制消息（`start`/`finish`）；`/ws/multicast` 是纯收听，连上即收结果。

### 1.1 transcript 消息（核心）

```json
{
  "type": "transcript",
  "lane_id": 0,
  "sentence_id": 3,
  "revision": 2,
  "is_partial": false,
  "is_final": true,
  "segment": {
    "text": "我们今天讨论一下进度。",
    "speaker": {
      "id": "spk_1",
      "label": "S1",
      "name": "张三",
      "confidence": 0.8231,
      "is_provisional": false
    }
  },
  "timestamp_ms": 12345
}
```

消息去重规则：`sentence_id + revision` 唯一标识一句话的一个版本；`is_partial=true` 是中间结果（会随 revision 递增被覆盖），`is_final=true` 是定稿。

**speaker 字段：**

| 字段 | 类型 | 说明 |
|---|---|---|
| `label` | string | 展示标签 `S1`/`S2`…，**页面上显示用这个** |
| `name` | string \| null | 声纹库命中的真实姓名；未命中为 `null` |
| `id` | string | 机器标识 `spk_1`…，前端一般不需要 |
| `confidence` | number | 0~1，命中声纹库时是比对得分 |
| `is_provisional` | bool | `true` = 临时归属（会话结束时可能被 `speaker_remap` 改掉） |

**展示建议：`name` 有值显示 `name`，否则显示 `label`：**

```js
const speakerName = seg.speaker ? (seg.speaker.name ?? seg.speaker.label) : '';
```

### 1.2 必须处理的边界情况

- **`speaker` 只出现在 `is_final=true` 的消息上**，partial 消息没有
- 以下情况 `segment` 里**没有 `speaker` 键**，取字段前必须判空：
  - 声纹功能未启用
  - 句子太短（< 1.2 秒提不出声纹）
- 声纹库为空时只分离不识别，`name` 恒为 `null`（属正常，不是故障）

### 1.3 speaker_remap 消息（会话末校准）

会话结束时服务端会做一遍全局重聚类纠正早期错分，标签有变化时下发（在 `saved` 消息之前）：

```json
{
  "type": "speaker_remap",
  "lane_id": 0,
  "mapping": { "S3": "S1" }
}
```

**必须原子套用整张表**——把本会话已展示的所有 `S3` 一次性替换为 `S1`。不能链式逐条替换（`S1→S2` 和 `S2→S1` 同时存在时会互相覆盖）。无变化则不下发这条消息。

```js
if (msg.type === 'speaker_remap') {
  const map = msg.mapping;              // {"S3": "S1"}
  for (const line of currentSessionLines) {
    if (line.speakerLabel in map) {
      line.speakerLabel = map[line.speakerLabel];
      // 若该行展示了 name，name 不受 remap 影响（remap 只改 label）
    }
  }
  rerender();
}
```

### 1.4 其他消息类型（一览）

| type | 说明 |
|---|---|
| `status` | 会话状态：`ready`/`started`/`paused`/`resumed` 等 |
| `config_ok` | `/ws/stream` 音频格式确认 |
| `multicast_ok` | `/ws/multicast` 收听建立成功 |
| `kws` | 唤醒词命中 `{keyword}` |
| `saved` | 转写文本已落盘 `{path}` |
| `finished` | 会话结束 |
| `summary` | 会议纪要（仅请求了摘要才有） |
| `error` | 错误 `{message}` |

## 2. 声纹库管理（REST）

注册/删除**即时生效，无需重启服务**（服务端自动热重载到所有转写进程）。

### 2.1 查询声纹库

```
GET /v1/speakers
```

```json
{"enabled": true, "speakers": [{"name": "张三", "count": 3}]}
```

`enabled` 为声纹功能总开关；`count` 是该人注册的语音条数。

### 2.2 注册声纹

```
POST /v1/speakers   (multipart/form-data)
```

| 字段 | 说明 |
|---|---|
| `name` | 姓名，1~64 字符 |
| `files` | 1~8 个 wav 文件，每个 ≤32MB（16bit PCM；采样率/声道不限，服务端自动转换）|

```js
const form = new FormData();
form.append('name', '张三');
for (const f of fileInput.files) form.append('files', f);

const resp = await fetch('http://<板子IP>:8000/v1/speakers', {
  method: 'POST',
  body: form,
});
// 200: {"ok":true,"name":"张三","enrolled":2,"total":2}
```

- **建议每人 3 段以上、每段 2~5 秒干净语音**，识别率主要取决于注册音频质量
- 每人最多 8 条，超出自动淘汰最旧；`total` 为注册后的总条数
- 任一文件失败则整个请求不落盘（不会产生半成品）
- **首次注册需加载模型，耗时约 10~20 秒**，前端要转 loading，不要超时设太短；之后每次约 1~3 秒/段
- 错误：`400` 音频无法解码/过短无声/参数非法（`detail` 里有具体文件名和原因）；`503` 声纹功能未启用或模型不可用

### 2.3 删除声纹

```
DELETE /v1/speakers/{name}        // name 需 encodeURIComponent
```

```js
await fetch(`http://<板子IP>:8000/v1/speakers/${encodeURIComponent('张三')}`,
            { method: 'DELETE' });
// 200: {"ok":true,"name":"张三"}   404: 该姓名不存在
```

## 3. 端到端时序（组播收听为例）

```
前端                          服务端
  |--- WS connect /ws/multicast?group=... --->|
  |<------ {"type":"multicast_ok"} -----------|
  |<------ transcript (partial) --------------|   说话中，无 speaker 字段
  |<------ transcript (final, speaker:S1) ----|   断句定稿，带说话人
  |<------ transcript (final, speaker:张三) ---|   声纹命中后直接给姓名
  |<------ speaker_remap {"S3":"S1"} ----------|   会话结束，原子替换旧标签
  |<------ saved ------------------------------|
```

延迟参考：说完话到收到 final（含纠错+声纹）约 1.6 秒。

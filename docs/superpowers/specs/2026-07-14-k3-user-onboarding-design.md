# K3 普通用户上手文档设计

## 目标

在飞书知识库中提供一页中文上手文档，让没有技术背景的用户能够在 SpaceMIT K3 / Bianbu 新环境完成项目准备、启动服务、打开浏览器并学习 HTML 互动教程。

## 受众与范围

- 受众统一为第一次接触项目的普通使用者；不按产品、销售或前台拆分。
- 环境仅覆盖 SpaceMIT K3 / Bianbu（RISC-V）。
- 不包含项目测试步骤、代码实现说明或性能调优。

## 文档结构

1. 项目简介：说明项目可将多路中文、英文音频同时转换为文字。
2. 第一次准备：提供从压缩源码传送、K3 必需系统组件、Python 3.13 环境、项目安装和模型下载的顺序命令。说明项目使用自带运行时和 `zipformer-streaming.tar.gz` 模型资源。
3. 启动服务：给出服务启动命令与浏览器地址格式。
4. 完成一次识别：用普通语言说明配置、加载、选择音频、开始、查看结果和卸载的顺序。
5. HTML 互动教程：明确静态教程位置 `docs/web-ui-tutorial.html`、如何在浏览器打开，以及必须按“配置 → Load → Start → Stop → Unload”完成练习。
6. 常见问题：仅覆盖服务不可访问、模型下载失败、模型未加载、没有识别结果等用户可判断问题，并说明需提供给技术人员的信息。
7. 完成检查清单：模型已准备、服务已启动、浏览器已打开、教程已完成、已看到识别结果。

## 交付与验收

- 成稿写入用户指定的飞书知识库页面。
- 关键命令可直接复制；每个步骤说明成功标志。
- 文中包含 HTML 教程的明确入口与学习顺序。

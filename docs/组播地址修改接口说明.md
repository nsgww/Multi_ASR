# 实时转写 — 修改组播地址接口说明

## 1. WebSocket 接口

- **地址**：`ws://<板子IP>:8000/ws/multicast`
- **协议**：WebSocket（JSON 文本帧）
- **默认组播**：`224.2.1.168:6020`

连接时可通过 URL 查询参数指定初始组播地址；连接后也可通过 JSON 消息动态切换组播地址。

---

## 2. URL 查询参数（可选）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `group` | string | `224.2.1.168` | 组播 IP 地址 |
| `port` | int | `6020` | 组播端口 |
| `local_ip` | string | `0.0.0.0` | 本地绑定 IP（多网卡时可指定） |
| `packet_bytes` | int | `1280` | 每个 UDP 包的字节数 |
| `use_full_packet` | bool | `false` | 是否使用整包音频 |
| `heartbeat_interval` | float | `5.0` | 心跳发送间隔（秒） |
| `wakeup` | bool | `true` | 是否启用唤醒词门控 |

示例：

```
ws://192.168.1.179:8000/ws/multicast?group=224.2.1.168&port=6020
```

---

## 3. 修改组播地址

### 消息格式

```json
{
  "type": "set_multicast_group",
  "group": "224.2.1.168"
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | 是 | 固定为 `set_multicast_group` |
| `group` | string | 是 | 新的组播 IP 地址 |

### 重要限制

- **必须先结束当前转写任务**，才能切换组播地址。
- 如果当前有正在运行的组播任务（已发送 `start`），服务端会返回错误：

```json
{
  "type": "error",
  "message": "cannot change group while job running; finish first"
}
```

正确流程：

1. 发送 `{"type": "finish"}` 结束当前组播任务
2. 等待返回 `ready_for_new_transcription`
3. 发送 `{"type": "set_multicast_group", "group": "224.2.1.179"}`
4. 发送 `{"type": "start"}` 开始新的组播转写

---

## 4. 完整消息示例

### 连接

```
ws://192.168.1.179:8000/ws/multicast
```

### 开始收听组播

```json
{"type": "start"}
```

服务端返回：

```json
{
  "type": "status",
  "status": "started",
  "lane_id": 0,
  "message": "listening 224.2.1.168:6020 on ifaces=[...]; WS disconnect will NOT stop this job — send finish to release"
}
```

### 切换组播地址

```json
{"type": "finish"}
```

等待返回：

```json
{
  "type": "status",
  "status": "ready_for_new_transcription",
  "lane_id": 0,
  "message": "multicast job stopped and lane released; send start to begin"
}
```

然后发送：

```json
{"type": "set_multicast_group", "group": "224.2.1.179"}
```

服务端返回：

```json
{
  "type": "multicast_ok",
  "group": "224.2.1.179",
  "port": 6020,
  "lane_id": -1
}
```

再发送：

```json
{"type": "start"}
```

---

## 5. 其他常用控制消息

| 消息 | 说明 |
|------|------|
| `{"type": "start"}` | 开始收听当前组播地址 |
| `{"type": "pause"}` | 暂停转写（组播继续接收，但不推给 ASR） |
| `{"type": "resume"}` | 继续转写 |
| `{"type": "finish"}` | 结束当前组播任务并释放 lane |
| `{"type": "finish", "enable_summary": true}` | 结束并生成纪要 |

---

## 6. 注意事项

1. **组播任务独立于 WebSocket 连接**：断开 WebSocket 不会停止组播接收；必须显式发送 `finish` 才会释放资源。
2. **切换地址前必须 finish**：`set_multicast_group` 不允许在任务运行中调用。
3. **端口号不变**：当前接口仅支持修改 `group`，`port` 需在连接时通过 URL 参数指定；如需同时修改端口，请断开重连。
